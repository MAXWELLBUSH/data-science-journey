Fundamentals of Data
1. Fundamentals of Data
What is Data?

Definition:
Data are collections of distinct values represented by characters, stored or used by a computer. They consist of raw, unprocessed, and unorganized facts that may appear random or meaningless until processed.

Characters (char):
Single objects representing text, numbers, and symbols. Examples include letters such as AB, digits such as 01, and special characters such as & and <.

Computer Processing:
Computers use character encoding systems such as ASCII to represent characters as numbers. These values are ultimately processed by computers as binary (0s and 1s).

Data Types & Storage Formats
Data Type	Examples / Subtypes	Common Storage Method
Boolean	True, False	Tabular format / Database tables
Text	Strings, e.g. "abcd"	Tabular format / Database tables
Numbers	Integers, Floats, e.g. 1234	Tabular format / Database tables
Complex Media	Images, Sound, Video	Stored via file paths in tables or as BLOBs (Binary Large Objects) in database tables
What is a Data Table?

A data table is a grid with data arranged in labeled rows and columns.

2. The DIKW Pyramid & Information

The DIKW Pyramid illustrates how raw data evolves into actionable decision-making tools:

Data: Raw, unfiltered, and unorganized facts.
Information: Data that has been processed and organized within a meaningful context, making it useful.
Knowledge: The understanding or comprehension of information derived from data.
Wisdom: The ability to make sound judgments and decisions based on experience, knowledge, and understanding.
Data vs. Information
	Data	Information
Nature	Raw, unorganized, and unfiltered	Refined, structured, and contextualized
Meaning	May be meaningless on its own	Provides meaningful conclusions
Dependency	Exists independently	Depends on processed data
Decision-making	Insufficient on its own	Can support decision-making
Example	Individual sales recorded by a cashier daily	Monthly total sales summarized to calculate profit or loss
3. Uses of Data & Data-Driven Decision-Making
Decision-Making

Using facts and evidence to guide decisions rather than relying solely on intuition.

Product Development

Using data to create or improve products and services that address customer and business needs.

Storytelling

Using data to provide context, evidence, and insights that support a narrative.

Data-Driven Decision-Making (DDDM)

Data-Driven Decision-Making (DDDM) is the process of using metrics and data-derived facts to make strategic decisions aligned with business goals, objectives, and KPIs (Key Performance Indicators).

Real-World Applications

Data can be used for:

Sales prediction
Purchasing behavior analysis
Fraud detection
Marketing campaign evaluation
Customer retention analysis
4. The Data Lifecycle

The data lifecycle describes the sequential stages data undergoes as it is collected, processed, used, stored, and eventually destroyed.

[1. Collection] → [2. Storage] → [3. Processing] → [4. Visualization]
                                                              ↓
[7. Destruction] ← [6. Archiving] ← [5. Dissemination] ←─────┘
1. Data Collection

Gathering data from sources such as:

Sensors
Surveys
Databases
Applications
Transactions
2. Data Storage

Securing data in an accessible and appropriate location, such as databases, data warehouses, or cloud storage.

3. Data Processing

Cleaning, transforming, organizing, and statistically analyzing raw data to prepare it for analysis.

4. Data Visualization

Presenting data using charts, graphs, dashboards, and other visualizations to make patterns and insights easier to understand.

5. Data Dissemination

Sharing data, findings, and insights with relevant stakeholders so they can use them for decision-making.

6. Data Archiving

Moving data to secure, long-term storage when it is no longer actively being used but may still need to be accessed in the future.

7. Data Destruction

Permanently deleting data when it is no longer needed, while following applicable security, legal, and compliance requirements.
