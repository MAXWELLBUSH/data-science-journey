Week 1 Learning Log — Foundations of Problem Solving & Programmatic Thinking

This week, I learned the fundamentals of data, data science, problem solving, Agile, and programmatic thinking.

What I Learned
Data Fundamentals: Learned what data is, different data types, how computers process data, the DIKW pyramid, Big Data, and the data lifecycle.
Data Science & Data Analytics: Understood the difference between data analytics and data science, and how data science combines computer science, mathematics/statistics, and business/domain knowledge.
Data Analysis: Learned about the data analysis process, including problem definition, data collection, cleaning, EDA, and reporting insights, as well as descriptive, diagnostic, predictive, and prescriptive analytics.
Problem Solving: Learned how to define clear problem statements, identify root causes, use MECE (Mutually Exclusive, Collectively Exhaustive) and logic trees to break complex problems into smaller parts.
Design Thinking: Learned the process of Empathize → Define → Ideate → Prototype → Test.
Agile & Scrum: Learned Agile principles and how Scrum organizes work through Sprints, Product Backlogs, Sprint Planning, Daily Scrum, Sprint Reviews, and Retrospectives, as well as the roles of Product Owner, Scrum Master, and Developers.
Programmatic Thinking: Learned about algorithms, operators, flowcharts, pseudocode, and conditional statements such as if, elif, and else.
Problem-Solving Logic: Practiced converting problems into logical steps and understanding how conditions and decisions can be represented using flowcharts and pseudocode.
Key Takeaway

This week taught me how to approach a problem systematically—from understanding the problem and structuring it logically, to analyzing data and designing solutions that can eventually be implemented programmatically.

Week 1 Reflection

I now have a stronger foundation in data science concepts, analytical thinking, problem solving, and programming logic, which will help me as I progress into Python, data analytics, and machine learning.
